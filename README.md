# Wedding AI Planner

**Интелигентна web-базирана система за планиране и управление на сватбени събития**

Дипломен проект по специалност „Компютърни системи и технологии“, разработен в Технически университет – София, филиал Пловдив.

## Описание

Wedding AI Planner е web-базирана система, която обединява основните дейности по планиране и организация на сватбено събитие. Системата предоставя инструменти за избор на услуги, генериране на ориентировъчни оферти, управление на резервации, AI консултиране, създаване на визуализации и интерактивно разпределение на сватбена зала.

Проектът е разработен като функционален прототип с модулна архитектура и интеграция на външни AI услуги.

## Основни функционалности

- Регистрация и вход на потребители.
- Избор и управление на сватбени услуги.
- Smart Offer Engine за генериране на персонализирани ориентировъчни оферти.
- Създаване на резервации.
- AI асистент със специализирана база от знания и RAG.
- Съхраняване на историята на разговорите.
- Генериране и съхраняване на AI сватбени визуализации.
- Интерактивен Hall Layout Planner с преместване и завъртане на елементи.
- Запазване и зареждане на разпределения във формат JSON.
- Автоматично генериране на разпределение на зала.
- AI анализ на създаденото разпределение.
- Dashboard с обобщена информация за потребителското сватбено събитие.

## Използвани технологии

| Компонент | Технологии |
|---|---|
| Frontend | HTML, CSS, JavaScript, Bootstrap |
| Интерактивна зала | Konva.js |
| Сървърна логика | PHP |
| AI backend | Python, Flask |
| База данни | MySQL |
| Езикови и визуални AI модели | OpenAI API |
| Семантично търсене | Sentence Transformers, ChromaDB |
| Архитектура на асистента | Retrieval-Augmented Generation (RAG) |

## Структура на проекта

```text
Diploma-Wedding-AI/
├── ai-module/              # Flask AI backend и RAG
├── backend/
│   └── php/                # PHP API и работа с MySQL
├── database/
│   └── schema.sql          # SQL схема на базата данни
├── frontend/               # HTML, CSS, JavaScript и изображения
├── start_project.sh        # Стартиране на локалните сървъри
└── stop_project.sh         # Спиране на локалните сървъри
```

## Необходими компоненти

За локално стартиране са необходими:

- PHP с необходимите разширения за MySQL;
- Python 3;
- MySQL Server;
- необходимите Python библиотеки за AI модула;
- OpenAI API ключ;
- съвременен web браузър.

Проектът е разработван и тестван в локална среда на macOS. За стартиране на друга операционна система може да е необходима адаптация на стартовите скриптове.

## Конфигуриране на AI модула

В директорията `ai-module` се използва локален файл `.env`, съдържащ необходимите конфигурационни стойности.

Примерен шаблон:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

Реалният API ключ не трябва да се публикува в GitHub. Файлът `.env` е изключен чрез `.gitignore`.

## База данни

SQL схемата на базата данни се намира в:

```text
database/schema.sql
```

За локално използване е необходимо да бъде създадена MySQL база данни и да бъде импортирана схемата. Настройките за връзка с базата данни трябва да съответстват на локалната MySQL конфигурация.

## Стартиране на системата

От основната директория на проекта:

```bash
./start_project.sh
```

Скриптът стартира PHP сървъра и Flask AI backend.

След успешно стартиране началната страница е достъпна на:

```text
http://localhost:8000/frontend/index.html
```

Dashboard:

```text
http://localhost:8000/frontend/dashboard.html
```

Flask AI backend:

```text
http://127.0.0.1:5000
```

## Спиране на системата

Системата може да бъде спряна чрез:

```bash
./stop_project.sh
```

или чрез `Ctrl + C` в терминала, в който е стартирана.

## Сигурност

Хранилището не трябва да съдържа реални API ключове, пароли, локални конфигурационни файлове, виртуални среди, кеш файлове или локалната ChromaDB база. Тези файлове се изключват чрез `.gitignore`.
